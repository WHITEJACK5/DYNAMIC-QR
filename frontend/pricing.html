Why is there no pricing table?

Because none is implemented. This build has no payment processor, no subscription records, and no plan-based limits — an earlier version of this page advertised paid tiers that the code never enforced. Everything the software can do is available to every account at no cost.

It is a self-hosted project: run it locally, or point it at your own database and storage. See the README for the DATABASE_URL and S3_BUCKET settings, and the manual for the API.
