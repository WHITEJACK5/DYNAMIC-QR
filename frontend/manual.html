DRQR — Working Manual

Local-first QR • Local SQLite data/DR.db • Tested on fresh Windows 11 + Python 3.11. Every command below was executed.

View Markdown → Health Check Dashboard

Fresh Install (Any PC)

git clone https://github.com/WHITEJACK5/DYNAMIC-QR.git
cd DYNAMIC-QR
cp .env.example .env   # or ./start.sh auto-creates
pip install -r requirements.txt
python app.py
# → Fresh DB created at data/DR.db
# open http://127.0.0.1:5000

No manual DB steps. app.py:31 creates data/ + .gitkeep, init_db() creates tables. Delete data/DR.db → restart → fresh.

Run Daily

# Windows
pip install -r requirements.txt
python app.py
# or .\start.ps1 / .\run.bat
# Unix/macOS
chmod +x start.sh && ./start.sh
# verify
curl http://127.0.0.1:5000/api/health

Generator

Pick type (All 25+), choose Static (free) vs Dynamic (trackable, needs login), fill form, customize Pattern/Eyes/Colors/Logo (drag PNG ≤5MB → 22% center)/Frame, Generate → Download PNG/SVG (real vector)/PDF. No confirm dialog.

Dashboard

/dashboard (auth-guarded) — Search/filter, View (analytics), Edit all fields (name/type/content/colors/pattern/frame/password/limit/expiry) → PUT /api/qrcodes/<id>, Duplicate, Delete, Bulk CSV, Folders, Templates, Settings (2FA).

2FA & Forgot

Register → Login; if 2FA enabled, `need_2fa` → enter 6-digit code (`/api/2fa/login-verify`). Dashboard Settings → Setup 2FA (scan QR) → Verify. Forgot? → Login modal `Forgot?` → `POST /api/forgot-password` → token in server logs → `POST /api/reset-password`.

Security

SECRET_KEY via .env (auto-generated), HOST=127.0.0.1 FLASK_DEBUG=false, rate limit 5/min, CORS whitelist, password via POST not GET, real geo via ip-api.com, real SVG/GS1/smart URL.

API

Method Path Purpose
POST /api/register Register
POST /api/login Login
POST /api/generate Generate QR
GET /r/<code> Redirect (track)
GET /api/download/<id> PNG/SVG/PDF
